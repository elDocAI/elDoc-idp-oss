## Scope

This inventory identifies the application dependencies resolved for `eldoc-idp-web` from the supplied parent/core/web POMs. The fourth POM, `eldoc-base-api`, declares only provided dependencies. Test/build-only dependencies, unused dependency-management entries and elDoc's own artifacts are excluded from the third-party runtime inventory. A dependency is included if Maven resolves it at compile/runtime scope, even if another declaration uses a different scope.
