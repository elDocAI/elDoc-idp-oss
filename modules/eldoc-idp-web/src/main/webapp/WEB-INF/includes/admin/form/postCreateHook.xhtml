Scripting hints:
The form definition and data are passed as the "workflow" variable, with the following properties:
* workflow._cfDef - (List<CustomField>) Provides access to the following properties of CustomFields: name, type, tags, enabled, required, _properties, etc. Writable properties are: enabled, required, and _properties
* workflow._cfData - (Map<String, Object>) Provides access to the values of CustomFields, where the key has the format cfX (X - index matching the custom field index) and the corresponding value
Hint: You may modify the provided workflow variable as needed and use "return workflow;" at the end of the script code to save the modified values.
