Scripting hints:
Extracted recognition data (recoData) for the document is passed as the "recoData" variable, with the following properties:
* recoData.fields - (List<Field>) Describes recoData fields: name, type, tags, value, etc.
* recoData.pageIdxStart - (Integer) The index of the page in the source document where the current recognition data (recoData) starts
* recoData.pageIdxEnd - (Integer) The index of the page in the source document where the current recognition data (recoData) ends
* recoData.validated - (Boolean) A flag indicating whether recoData was automatically validated
The global script scope (Map<String, Object>) can be accessed via the "scope" variable. This scope is shared between script invocations.
Hint: You may modify the provided recoData value as needed and use "return recoData;" at the end of the script code.
