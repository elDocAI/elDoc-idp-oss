Scripting Hints:
Field data is passed as the "field" variable, with the following properties:
* field.conf - (Integer) Confidence level of the captured value
* field.confThreshold - (Integer) Confidence threshold defined for the field
* field.name - (String) Name of the field
* field.tags - (List<String>) List of tags associated with the field
* field.type - (String) Type of the field; should be 'reco'
* field.validated - (Boolean) Whether the field was automatically verified
* field.value - (String) Value of the field
 * field.conf - (List<List<Integer>>) Confidence level of the captured values: A list (rows) of lists (columns) of integers (confidence per cell)
* field.fields - A list of fields with the same structure as this variable, describing each column
* field.name - (String) Name of the field
* field.tags - (List<String>) List of tags associated with the field
* field.type - (String) Type of the field; should be 'recoTable'
* field.validated - (List<List<Boolean>>) Flags indicating whether cell values were automatically validated: A list (rows) of lists (cells) of booleans (validation status per cell)
* field.value - (List<List<String>>) Value of the field: A list (rows) of lists (columns) of strings (values)
 * field.conf - (List<Integer>) Confidence level of the captured values: A list (marks) of integers (confidence per mark)
* field.confThreshold - (Integer) Confidence threshold defined for the field
* field.fields - A list of fields with the same structure as this variable, describing each optical mark
* field.name - (String) Name of the field
* field.tags - (List<String>) List of tags associated with the field
* field.type - (String) Type of the field; should be 'recoOmr'
* field.validated - (Boolean) Whether the field was automatically verified
* field.value - (List<Boolean>) Value of the field
 Global script scope (Map<String, Object>) can be accessed as the "scope" variable. The scope is shared between script invocations.
If a value different from the initial one is returned, the field's confidence level is set to 99%.
If the script does not return any value, the original field value and confidence level remain unchanged.
Hint: You may modify the provided field value as needed and use "return field;" at the end of the script code.
